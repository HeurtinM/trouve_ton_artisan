# Prérequis
-Node.js v22.15 ou supérieur
-npm 11.7 ou supérieur
-MariaDB 10.4.32 ou supérieur
-un fichier .env contenant les variables nécessaires

# Database
les .sql pour créé et alimenter la base de donné ce trouvent dans /database

## Commandes 
# Installation
npm install

# Lancer le serveur backend (depuis le dossier /server)
npm run devServer 

# Lancer le frontend en développement
npm start

# Build de production
npm run build
